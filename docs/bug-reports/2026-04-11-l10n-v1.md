# Bug Report — Localization Pass (FR + EN)

**Date:** 2026-04-11
**Build:** InfiniteStories Debug, iPhone 17 Pro (iOS 26.4)
**Tester:** Claude Code via XcodeBuildMCP
**Scope:** Two systematic walkthroughs of the app, once with simulator locale set to `fr_FR`, once with `en_US`. Goal was to surface untranslated strings, mixed-language screens, plural rules, format specifiers, and inconsistent capitalisation.

> **Note.** The FR session reused an existing account that had French user-generated content. For the EN session a new test user was created via the Sign Up form (per the user's request) since the pre-recorded sample stories are authored in French — any French text that is *obviously user content* (hero name "Caca le lézard", story titles, descriptions) is explicitly **not** a bug.

## French pass — detailed findings

### L10N-01 · `Home → "See all"` — Sev 🔴 P0
**Where:** `HomeContentView.homeRecentStoriesSection`, top-right affordance of the "Aventures Récentes" section.
**Observed:** Button text reads `See all`. AX label confirms literal "See all".
**Expected:** `Voir tout`.
**Likely cause:** String not keyed through xcstrings — the affordance was added in a recent home-layout fix (BUG-A24) with a `defaultValue:` fallback that was never translated.

### L10N-02 · `Story card badge — "Custom Event"` — Sev 🔴 P0
**Where:** `StoryCard` event badge for user-event-backed stories.
**Observed:** Badge reads `Custom Event` under French event name, also repeated in `AXLabel: "Event: Custom Event"`.
**Expected:** `Événement personnalisé` / `"Événement : <nom>"`.
**Likely cause:** Fallback branch in `Story.eventTitle` / `StoryCard` label when the custom event reference is a placeholder uses hardcoded English.

### L10N-04 · Trait rendering uses English rawValue — Sev 🔴 P0
**Where:** Heroes list card (`HeroListView`), Step-4 Hero preview, Story Generation hero header.
**Observed:** "Funny / Curious" chips in Heroes list; "Funny and Curious" in hero preview and `Generate New Story` header.
**Expected:** `Drôle / Curieux`, `Drôle et Curieux`.
**Note:** The Hero Creation step-2/step-3 trait picker grid **does** show the localised names correctly — only the *display* sites are bugged.
**Root cause:** `CharacterTrait.displayName`/`localizedName` likely falls back to `rawValue` in display call-sites.

### L10N-05 · Story event descriptions untranslated in FR picker — Sev 🔴 P0
**Where:** `StoryGenerationView` event picker, "Événements suggérés" list (11 built-in events).
**Observed:** Every card shows French `title` but English `description`, e.g.
- `Aventure du coucher` / `a calm bedtime adventure that helps prepare for sleep`
- `Journée d'école amusante` / `an exciting day at school with learning and fun`
- `Fête d'anniversaire` / `a magical birthday celebration with surprises`
- `Explorateur du week-end`, `Magie d'un jour de pluie`, `Moment en famille`, `Se faire des amis`, `Apprendre quelque chose de nouveau`, etc.

**Expected:** Localised French descriptions.
**Root cause:** `StoryEvent.eventDescription` returns the raw English string (likely a static extension returning the rawValue synonym), bypassing xcstrings entirely.

### L10N-07 · Story detail metadata row untranslated — Sev 🟠 P1
**Where:** `AudioPlayerView` header row and footer of the story detail sheet.
**Observed (FR):**
- `"384 words"` (expected `"384 mots"`)
- `"Played 0 times"` / `"Played 4 times"` (expected `"Lu 0 fois"` / `"Lu 4 fois"`)
- `"Created 31 déc. 2025 à 14:54"` (expected `"Créé le …"`)
**Root cause:** String interpolated directly in view — not routed through `String(localized:)` + plural variant.

### L10N-08 · Custom Event detail — chips + stats untranslated — Sev 🟠 P1
**Where:** `CustomEventDetailView` reached from the Custom Events management sheet.
**Observed (FR):**
- Mood badge `Cheerful` (expected `Joyeux`)
- Age range `All Ages` (expected `Tous âges`)
- Card footer `Never used` (expected `Jamais utilisé`)
- Every keyword chip: `school, friendship, adventure, first day, imagination, creativity, emotions, encouragement` — 100 % English despite French picker
- Prompt body `**Title: First Day at School** …` — English (user-created via English AI enhancement; see L10N-24 below).

### L10N-09 · Selected event trigger uses rawValue — Sev 🟠 P1
**Where:** `StoryGenerationView.eventSelectorView` — the row that shows the currently chosen event above `Générer l'histoire`.
**Observed (FR):** Trigger shows `Bedtime Adventure / A Calm Bedtime Adventure That Helps Prepare For Sleep` even though the picker below renders `Aventure du coucher`.
**Expected:** Selected row must use `event.localizedName` + `event.localizedDescription`, mirroring the list items.

### L10N-10 · Reading Journey TimeRange `.all` — Sev 🟠 P1
**Where:** `ReadingJourneyView` chart range segmented picker.
**Observed:** FR: `Sem... / Mois / Année / All Ti...`. EN: `Week / Month / Year / All Ti...` (truncated).
**Expected:** FR `Tout` (or `Toutes`), EN `All Time` (and give the segment enough width — currently clips).
**Note:** TimeRange.all was added in the v2 patch (`apiValue: "all"`, `days: 3650`) but `localizedName` wasn't keyed.

### L10N-11 · ContentUnavailableView double-language — Sev 🟠 P1
**Where:** Reading Journey empty state.
**Observed (FR):** Header `Aucune donnée d'écoute pour le moment` followed by body `No listening data yet this period. Play a story to get started.` — header French, body English.
**Expected:** Body localised to match header.

### L10N-12 · Missing plural rule for `Événements` — Sev 🟠 P1
**Where:** Custom Events management sheet, stats row.
**Observed (FR):** `1 Événements` — singular count with plural form.
**Expected:** xcstrings `variations.plural.one = "%lld Événement"`, `other = "%lld Événements"`.

### L10N-20 · Settings → Voice description untranslated (partial) — not yet confirmed
Scrolled past too fast in FR pass; verify that `"Chaleureuse et rassurante — idéale pour le coucher"` is keyed (it appears correct in FR).

## English pass — detailed findings

### L10N-03 · Sign-out confirmation alert hardcoded French — Sev 🔴 P0
**Where:** `SettingsTabContent` / legacy `SettingsView` — both the Debug Sign Out and the Advanced Sign Out buttons.
**Observed (EN locale):** Alert title `Se déconnecter ?`, body `Voulez-vous vraiment vous déconnecter ? Vous devrez vous reconnecter pour accéder à vos histoires.`, destructive button `Se déconnecter`, cancel button `Cancel` (the only English string in the dialog).
**Expected:** All four strings localised via xcstrings.
**Root cause:** String literals hardcoded at the `Alert(...)` site rather than going through `String(localized:)`.

### L10N-06 · "Histoires Écoutées" label hardcoded French — Sev 🔴 P0
**Where:** `ReadingJourneyView` stats grid, first card.
**Observed (EN):** The card shows `1 / Histoires Écoutées` alongside three correctly-English siblings (`Listening Time`, `Current Streak`, `Favorites`).
**Expected:** `Stories Heard` (or `Stories Played`).
**Root cause:** Missing xcstrings entry or literal `"Histoires Écoutées"` string constant.

### L10N-13 · Debug section English-only in FR — Sev 🟡 P2
**Where:** Settings `Debug Controls` block (FR locale).
**Observed (FR):** `Debug Controls` heading, `Auth Status: ✓ Signed In`, `User ID: …`, buttons `Sign In as Test User` / `Create Random Test User` / `Sign Out`, footer `Debug-only controls for testing authentication. Test user: test@example.com`. Second `Sign Out` in the Advanced section is also English.
**Expected:** Localised (or explicitly marked debug-only and gated to #if DEBUG if strings are truly dev-facing).
**Mitigating:** This section is only shipped in DEBUG builds, so lower priority — but the `Sign Out` button in the *Advanced* (non-debug) section is visible in production.

### L10N-14 · Event description Title Case vs lowercase — Sev 🟡 P2
**Where:** `StoryGenerationView` trigger vs picker list for the same event (EN locale).
**Observed:**
- Trigger: `A Calm Bedtime Adventure That Helps Prepare For Sleep`
- Picker list: `a calm bedtime adventure that helps prepare for sleep`
Same source string, two different cases, same view.
**Expected:** Pick one. Copy-of-record is lowercase per the list; drop any `.textCase(.uppercase)` / manual capitalisation on the trigger.

### L10N-15 · Custom Event detail — negative duration + mislabelled unit — Sev 🟡 P2
**Where:** `CustomEventDetailView`, "Statistiques d'Utilisation" / "Usage Statistics" grid.
**Observed:** Card value `-3 m.` with label `Âge` underneath. The label appears to mean "time since creation" but:
1. Sign is negative (layout or format bug)
2. Unit `m.` is ambiguous (minutes? months?)
3. Label `Âge` reuses the hero-age string rather than something like `Créé il y a`
**Expected:** Absolute value, unambiguous unit, purpose-specific label.

### L10N-16 · Library card date clipping — Sev 🟡 P2
**Where:** `StoryCard` right-edge date text in `ImprovedStoryLibraryView`.
**Observed:** First card date clips mid-word to `"Hi"` (FR "Hier") or `"Yes te…"` (EN "Yesterday"). Removed `.fixedSize(horizontal: true, vertical: false)` tradeoff from v2 patch.
**Expected:** Either widen the column or let the date reflow to a second line — not mid-word clipping.

### L10N-17 · Tab transition overlap — Sev 🟡 P2
**Where:** Root `MainTabView` with Liquid Glass tab bar.
**Observed:** First frame after tapping a new tab renders the previous tab's content blended with the new one — visible as doubled titles, e.g. `Bibli...Mdianaque Hdueroesries` when going Library → Heroes. Same in EN (`Managinge Heroourney`).
**Expected:** Full crossfade with opacity or a hard swap.
**Not reproducible 100%:** settled within ~300 ms on both locales.

### L10N-18 / L10N-19 · AX labels in English (visible to VoiceOver users only) — Sev 🔵 P3
**Where:** `HomeContentView` hero button + story cards (FR locale).
**Observed:**
- Hero AX help: `"Opens Caca le lézard's profile"` (EN — not localised).
- Story card labels include English tokens inside an otherwise French label:
  `"Le merveilleux anniversaire de Caca le lézard, Event: Fête d'anniversaire, Has audio, 3 minutes, Écouté 1 fois"`
- AX help for all story cards: `"Double tap to play audio. Actions available in rotor."` — English in FR.

## Non-l10n findings surfaced during the walkthrough

### L10N-21 · Tab-switch animation renders Heroes content on top of Library
Covered in L10N-17 above; noted twice because it's visible both FR and EN.

### L10N-22 · "Ap-\nprendre" chip hyphenation
**Where:** Custom Event management, category tag on custom event card.
Layout bug: "Apprendre" (8 letters) force-wraps with a hyphen inside a 44 pt chip. Drop `.hyphenationFactor` or widen the chip.

### L10N-23 · Sign Up tab — button label race
**Observed transiently:** CTA read `Sign In` for ~200 ms after switching tabs while `Full Name`, `Confirm Password` fields animated in. Resolved to `Create Account` after the tab transition settled.
**Likely cause:** The button label is driven by `isSignUp` but rendered before layout commits the new field stack.
**Not currently reproducible** after the screen settles — noting for awareness only.

### L10N-24 · AI enhancement output in wrong language
**Where:** Custom Event detail — `Prompt de l'Histoire` body.
**Observed:** An event created while app language was FR has its AI-enhanced prompt body entirely in English (`**Title: First Day at School** … **Setting:** A sunny morning …`). Keywords are also English.
**Hypothesis:** Either the backend `CustomEventAIAssistant` call does not pass `Accept-Language` / `language` hint, or the event was created during a session where the UI was FR but the backend defaulted to EN.
**Action:** Confirm the AI-enhance endpoint is receiving the hero/user locale and prompts the model in the target language.

### L10N-25 · Email field accepts and renders noise on AZERTY hardware keyboard
**Observed (EN pass, test setup):** Typing `entest+20260411@example.com` via the simulator hardware keyboard (with the sim stuck on a French layout) produced `&é"1entest_éàé§à'&&2exq,ple:co,` in the email field with **no validation warning**. The "Create Account" button remained enabled momentarily.
**Expected:** Live email-format validation should gate the submit button.
**Not strictly a l10n bug** but surfaced during the pass.
